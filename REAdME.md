# ChatGPT Discord Bot

A Discord bot powered by OpenAI's ChatGPT API. Users can mention the bot to get instant AI responses.

## Features
✓ Real-time ChatGPT integration
✓ Discord bot with command prefix
✓ Error handling
✓ Message context awareness

## Setup

### Prerequisites
- Python 3.8+
- Discord bot token
- OpenAI API key

### Installation

1. Clone repository
```bash
git clone https://github.com/yourname/chatgpt-discord-bot.git
cd chatgpt-discord-bot
```

2. Install dependencies
```bash
pip install discord.py openai
```

3. Set up environment variables

4. Run bot
```bash
python bot.py
```

## Usage
- Mention the bot in Discord: `@BotName Hello!`
- Bot responds with ChatGPT's answer
